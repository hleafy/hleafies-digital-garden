# 网络层：完成计算机之间交换数据包
## 规则
* 每个计算机拥有唯一不可改的 mac地址（硬件地址）和可改变的 IP地址。计算机通信需要知道对方的IP地址
* 交换机用于简化网络。其每个端口连接一个计算机，所以每个端口对应一个mac地址，需要维护一个mac地址表。将IP地址和mac地址对应起来是由ARP学习机制实现（广播+回应+存储）
* 路由器用于进行交换机之间的传输，其每个端口连接一个交换机。路由器每个端口拥有一个mac地址和IP地址。为了判断接受方是否在子网内，引入IP地址。同一子网内的IP地址的前几位相同，或者说IP地址和子网掩码求与后相同。计算机通过此方法计算是不是要把数据包发给路由器。计算机需要知道默认网关，即路由器的IP地址。路由器中有路由表，记录端口和IP地址范围的对应关系。若转发后不能到达，可以发送给下一跳的路由器
## 节点行为

电脑：
1. 要知道我的 IP 以及对方的 IP
2. 通过子网掩码判断我们是否在同一个子网
3. 在同一个子网通过 arp 获取对方 mac 地址发送
4. 不在通过 arp 获取默认网关的 mac 地址发送

交换机：
1. 收到的数据包必须有目标 MAC 地址
2. 通过 MAC 地址表查映射关系
3. 查到了就按表从指定端口发出去
4. 查不到就所有端口都发出去，通过 ARP学习

路由器：
1. 收到的数据包必须有目标 IP 地址
2. 通过路由表查映射关系
3. 查到了按表从指定端口发出去
4. 查不到返回一个路由不可达的数据包
